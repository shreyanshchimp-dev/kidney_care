Kidney Care Hospital website

Files:
- index.html: page markup and JavaScript interactions
- styles.css: all page styling, design tokens, and responsive rules
- assets/: images used by the page

To run locally, keep index.html, styles.css, and the assets folder together, then open index.html in a browser or serve this folder using a local web server.

For future pages, link the shared stylesheet in each HTML page with:
<link rel="stylesheet" href="styles.css">
